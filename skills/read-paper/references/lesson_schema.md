# lesson.html schema —— 跨领域教学版(v1.5)

> **v1.6(2026-09-04)适用范围**:本文件的写法现在管的是 `note.html` 的**「讲义」tab**;不再生成独立 lesson.html。"符号速查仍走 qa.md"改为"符号表 tab";"批判/评价仍走 paper-card"改为"一屏卡左栏"。


> **定位**:用户在自己的非主场领域深读 paper 时的**主读材料**。note.html 是"原文的中文替身",lesson.html 是"一个懂行的朋友坐在旁边从零教你"。两者并存,lesson 叠在 note 之上,不替代。

## 何时产 / 不产

- **产**:paper 属于用户非主场领域且深读;或用户明说"教我 / 看不懂 / 当我是初学者"
- **不产**:主场领域 paper(faithful note 就够);skim 档
- 用户画像(什么算主场)查 memory / 对话上下文;不确定就问一句

## 核心写法:五条铁律

1. **先例子,后定义**。任何形式化对象($Q$、$F$、算子、骨架……)出场前,先用 running example 里的具体东西把直觉立起来,然后才说"数学上我们把它写成…"。顺序反了就是堆砌词藻。
2. **一个 running example 贯穿全篇**。选一个用户已熟悉的场景(优先复用他之前材料里的例子),所有概念都落在同一个场景上,不要每节换例子。
3. **推导拆到不能再拆,代入具体数字**。"$\tau:[0,1]\to Q$" 不许直接出现;要写"想象一个播放进度条 $\lambda$,拖到 0.5 时机器人姿势是 $\tau(0.5)=(90°, -30°)$…"。每一步变形单独一行,说明为什么可以这样变。
4. **每课结尾"回到原文"**。一个小框:学完这课,你现在能读懂 note.html / 原文的哪几节、哪些记号;还差什么下一课补。这是 lesson 与 note 的挂钩点。
5. **利用用户已有的领域做类比**(他是 ML/VLA 专家):"这就像 policy 的 rollout"、"相当于 rejection sampling"。类比要诚实标出在哪里失效。

## 结构约定

- **不跟随 paper 章节顺序**——按理解曲线排"课"(第 0 课、第 1 课…),每课一个认知台阶
- 第 0 课永远是:用用户已会的语言把整篇 paper 的问题说清楚(他为什么要关心)
- 最后一课永远是:收口 + 全篇"课 ↔ 原文 section"映射总表 + 回答阅读计划里挂着的必答题(如果有)
- 中间课数不限,每课 10–20 分钟阅读量

## 边界(不许犯)

- **不许编造 paper 没有的结论**;教学装置(自造的例子、数字、类比)要能被读者识别为教学装置(用"想象/比如/我们造一个玩具例子"引导)
- 不许把 note.html 的转写内容整段复制进来充数
- 批判/评价仍走 paper-card;符号速查仍走 qa.md(lesson 里出现的记号要与 qa.md Q1 一致)
- 语气:教,但不哄。用户是聪明的外行,不是小学生——类比可以密,废话不行

## 载体

单文件 HTML,house style 与 note.html 同一套(KaTeX CDN、sticky 目录、语义色块、紧凑表格),另加教学专用元素:
- 例子框(running example 的推进,统一颜色)
- 推导框(编号步骤,每步一行 + 为什么)
- "你可能会想问"折叠/侧栏(预判外行的困惑,直接回答)
- "回到原文"框(每课结尾,链接 note.html 对应锚点)
