# 一屏卡·图片版 绘制规范(read-paper v1.7.1,2026-09-12)

> 用户 09-12 要求:一屏卡要是**图片**,skill 里说清楚怎么画。本文件是那份说明;生成脚本 `scripts/card_svg.py`,输入一个 JSON、输出一张 SVG。第一版先看效果,规则会按反馈改。

## 0. 定位

- 一屏卡图 = 这篇论文的**一屏海报**:打开 note 第一眼看到的东西,不滚动就能读完,读完知道这篇是什么、从哪来、硬在哪、空在哪。
- 它是**压缩版**。七行的全文仍保留在图下方的折叠区(默认收起),用户右栏四个作答框也在图下方。图里不放用户的字。
- 载体:note 里是**内联 SVG**(矢量、可复制文字);论文目录同时落 **`card.png`(2x,真正的图片文件,点图打开)**、`card.svg`(矢量)、`card.json`(源数据)。

## 1. 画布与网格(09-12 第二版:按用户反馈"字太小,多铺开")

- 画布宽 **860**,高度按内容算(Zhu 那篇 ≈ 940)。note 的内容栏在 1280 屏上是 851 px,所以图在页面里**约 1:1 显示**,不缩。宽高比不固定,"一屏"让位给"能读"。
- 外边距 16,栏内 padding 12,圆角 8;两栏时左栏宽 404、右栏宽 396,栏距 12。
- 五个横带,从上到下:

| 带 | 内容 |
|---|---|
| ① 标题带 | 中文标题(21px 粗)+ 元信息(12px,≤2 行:作者 · 机构 · **发表:录用刊物 + 年(未查到就写 arXiv 预印本)· 奖项:查到的奖 + 来源类型(官方 / 报道),没有就不写** · 读于);右上角判决徽章 **主要成立于 X 镜 · Y 镜空** |
| ② 脊椎带 | 标签「脊椎」+ 正文 15px,淡蓝底,≤3 行 |
| ③ 双栏带 | 左栏 **脉络**:五节点竖排成时间线,每节点 = 名字 + 出处标签 + ≤3 行正文;右栏 **三镜**:三块竖排(每块 ≤3 行)+ 一行结论 + **钉子候选**红框(≤5 行)。钉子长在空的那一镜下面,所以放右栏 |
| ④ 四格带 | 本线四格横排,四格等高(≤4 行) |
| ⑤ 底带 | 左 **边界**(≤3 条,每条 ≤3 行)· 右 **一句话裁决**(≤6 行),两框等高 |
| ⑥ 名词带 | **必有。** 卡上出现过的每一个**主场外**的缩写、方法名、人名 / 机构名、行话,一条一行白话解释,两栏。主场词(BC、diffusion policy、DAgger、VLA、遥操、在线 / 离线蒸馏)不放,用户 09-12 原话"BC diffusion 这种不需要解释";拿不准就放 |

- 换行:中文逐字、英文按整词(字母数字和 `-./%` 连成一个词),标点不落行首。行数超限报错,不缩字。

## 2. 每格字数上限(09-12 第三版:为"每个词都解释"放宽;仍是硬上限,超了删字不缩字)

| 格 | 上限(中文字数,英文按 0.55 字算) |
|---|---|
| 标题 | 30 |
| 脊椎 | 150 |
| 脉络每节点 | 各 100,外加一个出处标签 ≤12 |
| 三镜每镜 | 各 120,外加"硬 / 软 / 空"徽章 |
| 四格每格 | 各 90 |
| 边界每条 | 3 条 × 60 |
| 裁决 | 120 |
| 钉子候选 | 160,末尾固定"候选,未验证" |
| 名词每条 | 110 |

**说人话优先于压缩。** 每格先用白话写,缩写第一次出现时括号里给一句白话(例:RRT(随机撒点找路的规划器));写不下再删修饰语、例子、并列项。绝不靠"去掉解释"来省字。凡是卡上出现的主场外缩写 / 方法名 / 人名,名词带里必须有一条;主场词(见 SKILL 硬规矩 10)不解释。

## 3. 字号与颜色

- 字号:标题 21,带标签 13.5 粗,正文 14(脊椎 15),出处标签 11.5 灰。**任何文字不小于 11.5px**,页面里不缩放,所以见到的就是这个字号。
- 字体:`-apple-system, "PingFang SC", "Hiragino Sans GB", sans-serif`;数字与英文同字体,不用等宽。
- 颜色沿用 house palette:墨 `#1a1d23`、灰 `#5a6270`、线 `#e3e6eb`、蓝 `#0f62fe` / 淡蓝 `#eef4ff`、绿 `#0e6027` / 淡绿 `#e9f6ec`、黄 `#8a6a00` / 淡黄 `#fff8e1`、红 `#a2191f` / 淡红 `#ffefef`、紫 `#8a3ffc` / 淡紫 `#f6f0ff`。
- **语义固定**:三镜徽章 硬=绿、软=黄、空=红;钉子候选框=红边淡红底;脊椎带=淡蓝;脉络节点=白底灰边,时间线为蓝线;四格=淡紫;边界=淡黄;裁决=淡绿。
- 不用图标、不用渐变、不用阴影、不用装饰性插画。信息密度靠版式,不靠视觉噪音。

## 4. 每格写什么(与 note_schema_v2 §9 一致,只是压缩)

- **标题带徽章**:直接复用三镜的最后两句,格式 `主要成立于 AI 镜 · ML 镜空`。
- **脉络五节点**:每节点一句,句末出处标签 `[原句 Sec 1]` / `[引用数据]` / `[agent 判断]`,标签 11px 灰。节点间用竖线相连,表示时间顺序。
- **三镜**:每镜一行标签 + 徽章,下面正文 ≤2 行。正文必须含一个数字(robotics)或一个"量"的名字(AI)或一个"机制 / 证明"的名字(ML);写不出就说明那一镜是空的,徽章打红。
- **四格**:本线四格的名字作标签(TAMP 线:谓词 / 算子 / 规划器 / 噪声;70 线:监督从哪来 / teacher 给什么 / student 怎么学 / 部署差距)。
- **钉子候选**:一个问句 + "只有…能填"一句,末尾"候选,未验证"。

## 5. 生成与嵌入流程

1. agent 先写好七行全文(HTML,进折叠区),再从中**压缩**出 `<paper-dir>/card.json`(字段见 `scripts/card_svg.py` 顶部注释),自检每格字数。JSON 留在论文目录,改字只改 JSON 再重跑。
2. `uv run <SKILL_DIR>/scripts/card_svg.py card.json --out <paper-dir>/card.svg`。脚本按 §2 的宽度做贪心换行(中文 1 em、ASCII 0.55 em),超出行数上限时报错而不是缩字。
3. 出 PNG:把 svg 塞进一个 `margin:0` 的空 html,Chrome headless `--window-size=860,<H> --force-device-scale-factor=2 --hide-scrollbars --screenshot=<paper-dir>/card.png`(H 读 svg 的 height 属性)。Chrome 退出时可能挂住,用 40 s 看门狗 kill,文件已经写好。
4. 内联进 note.html 的 `<section class="card">`:`<div class="svgwrap cardimg"><a href="card.png" target="_blank">…svg…</a></div>` → 一行说明 `.cardcap` → `<details class="cardfull"><summary>七行全文</summary>…七行全部 row solo…</details>` → `.mineblock` 用户四个 textarea(脊椎 / 四格 / 边界 / 裁决)→ `#cardstatus`。localStorage 逻辑不变。
5. 视觉验证:看 card.png 本身(字有没有被掰断、框有没有溢出),再截 note 1280 宽一张看图是否 1:1、没有横向滚动。Chrome 不可用时 `qlmanage -t -s 1600 -o <dir> card.svg` 能出缩略图。都不可用就明说。
