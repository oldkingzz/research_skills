# 子技能目录

每个子技能一个文件夹，内含自己的 `SKILL.md`。

- **`read-paper/`** — 读论文方法论（v1，自建）。「先赌后验」式深读，承重数学进 qa.md。
- **`ml-paper-writing/`** — 写论文（整包搬自 Orchestra-Research，原样）。重点资产是 `references/writing-guide.md`。

来源说明：`ml-paper-writing` 来自开源仓库 Orchestra-Research/AI-research-SKILLs（98 个 skill 里唯一对本用户可整包直接用的）；其余 96 个多为工程实现类（训练/微调/推理/量化），不复现实验则用不上，未搬。
